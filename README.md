# 学習ログ

このレポジトリは、学習ログアプリに育てるための土台として使います。

HTML/CSS/JavaScriptとlocalStorageで動く、学習内容・学習時間・気づきを記録するアプリです。日付ごとに複数の学習記録を保存でき、同じ日に教科や学習内容を分けて記録できます。

## 使い方

`index.html`をブラウザで開き、学習した日、学習したこと、学習時間を入力して保存します。学んだことや気づきのメモは任意です。学習内容は60文字まで、学習時間は1〜1,440分、メモは240文字まで入力できます。

日付を選ぶと、その日に保存した記録のうち最後に更新したものが入力欄に表示されます。そのまま保存すると新しい記録として追加されます。既存の記録を変更する場合は、一覧の「編集」ボタンを使ってください。記録は一覧で確認でき、削除、キーワード検索、学習内容による絞り込みもできます。

## 機能

- 学習日、学習内容、学習時間、メモの記録
- 同じ日付に複数の学習記録を保存
- 学習時間の合計、学習した日数、記録数の表示
- 学習内容ごとの合計学習時間の表示
- 記録の編集と削除
- キーワード検索と学習内容による絞り込み
- ブラウザのlocalStorageへの保存

## プライバシー

記録は使用中のブラウザ内に保存され、別の端末やブラウザとは自動で共有されません。アプリには名前・住所・学校名などの個人情報を入力しないでください。

## 保存データ

保存キーは`study-log.entries.v1`です。記録は次のようなデータとしてブラウザに保存されます。

```json
[
  {
    "id": "example-id",
    "date": "2026-10-22",
    "subject": "英語",
    "minutes": 30,
    "note": "単語を復習した",
    "createdAt": "2026-10-22T10:00:00.000Z",
    "updatedAt": "2026-10-22T10:00:00.000Z"
  }
]
```
